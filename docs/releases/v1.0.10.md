# OwnClip v1.0.10

发布日期：2026-11-20

## 新增

- 新增版本检查：支持在设置中手动检查 GitHub 最新正式版本，并在发现新版本时打开下载页面；启动及进入通用设置时也会按缓存策略后台检查。
- 新增菜单栏图标显示开关。隐藏图标后，可通过剪贴板历史快捷键或从 Finder 重新打开 OwnClip，进入设置恢复显示。

## 优化与修复

- 菜单栏菜单使用系统原生样式显示当前快捷键，修改、停用或恢复快捷键后同步更新，支持方向键和功能键等特殊按键。
- 改善设置窗口的激活与焦点处理，打开设置时恢复最小化窗口。
- 调整通用设置布局，集中展示版本检查、开机启动、菜单栏图标与语言选项，并在设置底部增加退出按钮。
- 更新 OwnClip 应用图标和菜单栏图标，完善中英文文案及安装说明。
- 安装包文件名加入版本号，便于识别和保留不同版本。

## 下载与安装

- 安装包：`OwnClip-1.0.10.dmg`
- 系统要求：macOS 14 或更高版本，Apple Silicon（arm64）。
- 打开 DMG，将 `OwnClip.app` 拖入“应用程序”。
- 当前安装包使用固定的本地自签名证书，未经 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。
- 版本号：`1.0.10`；构建号：`11`。
