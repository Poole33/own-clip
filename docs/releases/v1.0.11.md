# OwnClip v1.0.11

发布日期：2026-11-24

## 优化与修复

- 改善首次授权后的引导：返回 OwnClip 后，确认已授权且需要重启时，弹框提示「已授权，重启后生效」，可选择「立即重启」或「稍后」。
- 同一次授权只提示一次；选择稍后，仍可在通用设置的权限区域重启 OwnClip。权限已生效时不提示重启。
- 完善重启提示的中英文文案及使用说明。
- 分别提供 Apple Silicon 和 Intel 安装包，文件名标明版本号和架构，便于选择。

## 下载与安装

- Apple Silicon（M 系列）安装包：`OwnClip-1.0.11-arm64.dmg`
- Intel 安装包：`OwnClip-1.0.11-x86_64.dmg`
- 系统要求：macOS 14 或更高版本。
- 打开对应架构的 DMG，将 `OwnClip.app` 拖入“应用程序”。
- 当前安装包使用固定的本地自签名证书，未经 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。
- 版本号：`1.0.11`；构建号：`12`。
