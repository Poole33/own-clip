# OwnClip v1.0.11

发布日期：2026-11-24

## 优化与修复

- 每次启动或从 Finder 重新打开时，按实际权限状态提示授权；撤销权限、卸载后重新安装，也会在缺少权限时提示。
- 授权成功后弹框提示「已授权，重启后生效」，可选择「立即重启」或「稍后」；即使权限已立即生效，也会提示一次。同一次授权不重复提示，撤销后重新授权会再次提示。
- 修复权限已生效时点击「立即重启」没有响应的问题，设置页和弹框共用重启操作。
- 补齐直接在系统设置中授权、首次检查未通过后再次授权的自动复查流程。
- 授权后重启或从权限入口打开设置时，自动定位到「权限」区域；成功时明确显示授权已生效，失败时可打开系统设置或重新检查权限。
- 统一自动粘贴与文件剪切的「已启用」样式，均显示绿色勾选，并完善中英文文案及使用说明。

## 下载与安装

- Apple Silicon（M 系列）安装包：`OwnClip-1.0.11-arm64.dmg`
- Intel 安装包：`OwnClip-1.0.11-x86_64.dmg`
- 系统要求：macOS 14 或更高版本。
- 打开对应架构的 DMG，将 `OwnClip.app` 拖入“应用程序”。
- 当前安装包使用固定的本地自签名证书，未经 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。
- 版本号：`1.0.11`；构建号：`12`。
