# OwnClip

OwnClip 是本地运行的 macOS 菜单栏剪贴板。安装包针对 Apple Silicon 构建，应用使用 macOS 14 或更高版本的系统框架。

## 安装

1. 打开 `dist/OwnClip.dmg`，把 `OwnClip.app` 拖到「应用程序」，再从「应用程序」启动。
2. 首次打开时，按提示进入系统设置，在「隐私与安全性」中允许 OwnClip 控制设备。也可稍后从「设置 → 通用」开启。返回 OwnClip 后会自动复查，若授权仍未对当前进程生效，可点「重启 OwnClip」。若顺序粘贴提示启用输入监控，可从同一窗口打开对应的系统设置。macOS 弹出剪贴板读取提示时，允许 OwnClip 读取才能自动记录历史。
3. 如果系统因安装包的下载来源阻止首次打开，按系统提示在「隐私与安全性」确认打开本机自用版本。安装包使用本地签名。

## 使用

| 操作 | 默认快捷键 |
| --- | --- |
| 打开剪贴板历史 | `⌘⇧V` |
| 打开顺序粘贴 | `⌘⇧C` |
| 粘贴历史中选中的条目 | `Return` |
| 粘贴为纯文本 | `⌘Return` |
| 粘贴搜索结果或历史的第 1–10 条 | `⌘1` 至 `⌘0` |
| 关闭当前 OwnClip 窗口 | `Esc` 或 `⌘W` |
| 粘贴下一条 | `⌘V` |

在「设置 → 快捷键」中可逐项改键。剪贴板历史快捷键在剪贴板历史面板获得焦点时生效。

「设置 → 通用 → 语言」提供「自动、English、简体中文」，默认自动。自动按系统首选语言匹配英文或简体中文，无法匹配时使用 English。切换后立即生效并保存，无需重启；菜单、面板、权限引导和应用提示同步更新。复制内容、文件名保持原文，macOS 权限弹窗由系统决定语言。

「设置 → 通用 → 登录时自动启动 OwnClip」默认关闭。打开后，macOS 会在你登录账户时启动 OwnClip。

底部长条铺满当前屏幕的宽度，每次打开时从第一张卡片开始。在卡片区域可以用普通鼠标滚轮、`Shift` 加滚轮或触控板横滑来横向滚动。浮动列表可用顶部拖动手柄移动，OwnClip 会记住每块显示器上的位置。打开设置时剪贴板历史面板会保留。`Esc` 和 `⌘W` 关闭当前获得焦点的 OwnClip 窗口；有确认弹框时，先取消确认弹框。录制快捷键时，`Esc` 取消录制，`⌘W` 关闭设置。这两个键保留为标准窗口操作，自定义关闭快捷键仍可额外使用。

剪贴板历史和顺序粘贴使用系统原生弹出窗口材质，随浅色、深色外观变化。横向历史卡片使用浅色模式白色、深色模式对应的系统背景；竖向历史列表未选中时背景透明。历史与顺序粘贴的下一条高亮共用系统选中背景色和配套文字色，均不显示条目边框，缩略图保留原色。三种展示的背景材质及选中配色集中配置在 `Sources/UI/PanelStyle.swift` 的 `PanelStyle` 中，背景保持原生材质效果。macOS 26 及以后，工具栏使用系统 Liquid Glass。开启系统「降低透明度」时，面板改用不透明的系统背景。

若系统开关已打开但 OwnClip 仍显示「未获得授权」，退出并重新打开。从旧的临时签名版本切换到固定证书签名版本时，需要移除旧授权，再添加「应用程序」里的当前版本一次。后续持续使用同一证书和 Bundle ID 构建，通常可以保留授权；若更换签名身份或遇到系统权限异常，仍可能需要重新授权。

主动打开顺序粘贴时，弹框会获得键盘焦点；从历史添加条目时保留历史窗口的焦点。顺序粘贴弹框在所有桌面可见，切换桌面不会清空队列或主动抢焦点。打开后继续在其他应用复制或剪切，按 `⌘V` 逐条粘贴。弹框顶部可切换「用后移除」和「循环使用」。默认的「用后移除」会逐条移除已贴内容，贴完后关闭弹框。「循环使用」保留所有条目，本轮贴过的条目变灰，贴完最后一条后从第一条开始新一轮。反转按钮可调整粘贴顺序。关闭顺序粘贴后，`⌘V` 恢复普通粘贴。顺序粘贴弹框可用顶部拖动手柄或空白区域移动，与剪贴板历史分别记住每块显示器上的位置，关闭重开或重启应用后会恢复。首次打开位于当前屏幕右上角，屏幕尺寸变化时会调整到可见范围内。

文本编辑和 Finder 文件名编辑使用原生 `⌘X`。在设置里开启 Finder 文件移动后，还可以选中文件按 `⌘X`，到目标目录按 `⌘V`，由 Finder 移动文件。

历史存放在 `~/Library/Application Support/OwnClip`，默认保留 1 天，可选 1–7 天。Finder 文件和视频记录保留原文件引用，原文件不可访问时会提示。直接复制的图片和视频数据存到本机。

## 项目结构

项目使用一个 Swift 应用模块，按功能和系统职责组织文件，无第三方依赖。

| 目录 | 职责 |
| --- | --- |
| `Sources/main.swift` | 程序入口 |
| `Sources/App/` | 应用生命周期、状态协调、菜单栏和重启 |
| `Sources/Features/History/` | 历史界面、卡片及面板布局参数 |
| `Sources/Features/SequentialPaste/` | 顺序粘贴界面和队列模型 |
| `Sources/Features/Settings/` | 设置界面 |
| `Sources/Services/` | 剪贴板监听、粘贴焦点等待、权限、快捷键配置和 Finder 文件移动 |
| `Sources/Platform/` | 原生窗口、快捷键注册、事件监听和 Finder 焦点检查 |
| `Sources/Models/` | 剪贴板内容的数据结构与格式转换 |
| `Sources/Storage/` | SQLite 历史索引和内容文件存储 |
| `Sources/Preview/` | 图片、视频缩略图和缓存 |
| `Sources/UI/` | 公共视觉样式、工具栏组件和滚动行为 |
| `Sources/Localization/` | 语言选择与界面文案 |
| `Resources/` | 应用 Bundle 配置 |
| `Tests/` | 按职责分组的回归测试与测试入口 |
| `Tools/` | 源文件收集、测试、签名和图标生成工具 |
| `dist/` | 构建生成的应用、DMG 和调试符号 |

`AppController` 连接服务并协调历史、顺序粘贴和设置。服务负责各自的状态和系统操作，通过回调报告结果；原生窗口由 `WindowCoordinator` 管理，界面放在对应的功能目录。

常用修改入口：

- 历史面板的尺寸、搜索栏边距和卡片上下间距：`Sources/Features/History/HistoryLayout.swift`。
- 面板材质、选中颜色：`Sources/UI/PanelStyle.swift`。
- 快捷键默认值与作用范围：`Sources/Platform/Shortcuts/ShortcutSettings.swift`。
- 中英文界面文案：`Sources/Localization/AppText.swift`。

新增 Swift 文件放在对应职责目录即可，构建和测试脚本会递归收集源码。测试排除应用入口，编译其余全部源码，以覆盖文件拆分后的集成关系。测试使用独立剪贴板、临时目录和独立偏好设置，不发送真实粘贴按键。

## 构建

在 macOS 上安装 Xcode 命令行工具。首次构建前初始化固定的本地代码签名证书，然后构建：

```bash
./Tools/setup-signing.sh
./build.sh
```

初始化脚本会生成有效期 10 年的 `OwnClip Local Code Signing` 自签名证书，将证书和私钥导入当前用户的默认钥匙串，并仅为代码签名设置信任；macOS 可能弹出确认窗口。重复运行会复用已有证书，不会重新生成。若已有证书缺少私钥、过期或未受信任，脚本会报错，应修复原证书而不是新建同名证书。可用 `./Tools/setup-signing.sh --check` 只检查配置。

输出为 `dist/OwnClip.app`、`dist/OwnClip.dmg` 和 `dist/OwnClip.app.dSYM`。只构建应用和调试符号时可运行 `./build.sh --app-only`。默认使用当前架构和固定的本地证书；证书不存在或不可用时会停止，不会退回临时签名。也可通过 `OWNCLIP_SIGN_IDENTITY` 指定其他证书的完整名称或 SHA-1 指纹；不接受 `-` 临时签名。发布时按版本保留应用和 `.dSYM`，用 `xcrun dwarfdump --uuid` 核对它们与崩溃报告中的 UUID 一致。

可将同一份签好的安装包用于多台 Mac；每台 Mac 首次安装仍需单独授予权限，之后使用同一签名身份升级。其他电脑只需安装应用，无需导入签名私钥。自签名不等于 Apple Developer ID 或公证，下载后首次打开仍可能需要在系统设置中允许。

请保留钥匙串中的证书和私钥。更换构建电脑时，可通过「钥匙串访问」安全导出为带密码的 `.p12` 并导入新构建电脑，同时恢复代码签名信任；不要将私钥、`.p12` 或密码放进项目或安装包。重新生成同名证书并不是同一个签名身份，会导致重新授权。

运行 `./Tools/smoke-test.sh` 可验证原生剪贴板格式、历史保留和快捷键配置。测试使用独立的剪贴板和临时目录。

正式分发需要在签名机的钥匙串中安装 Developer ID Application 证书及私钥，并用 `xcrun notarytool store-credentials` 配置公证凭据。使用钥匙串中的完整签名身份名称和公证配置名构建：

```bash
OWNCLIP_SIGN_IDENTITY='Developer ID Application: Your Name (TEAMID)' \
OWNCLIP_NOTARY_PROFILE='OwnClip' ./build.sh
```

脚本会启用 Hardened Runtime，签名并提交 DMG，等待 Apple 接受后附加并验证公证票据。正式分发时使用生成的 `dist/OwnClip.dmg`。
