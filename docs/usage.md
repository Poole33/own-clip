# 使用指南

[返回 README](../README.md)

## 安装


1. 从 [GitHub Releases](https://github.com/Poole33/own-clip/releases/latest) 下载 `OwnClip.dmg`，打开后把 `OwnClip.app` 拖到「应用程序」，再从「应用程序」启动。从源码构建的安装包位于 `dist/OwnClip.dmg`。
2. 首次打开时，按提示进入系统设置，在「隐私与安全性」中允许 OwnClip 控制设备。也可稍后从「设置 → 通用」开启。返回 OwnClip 后会自动复查，若授权仍未对当前进程生效，可点「重启 OwnClip」。若顺序粘贴提示启用输入监控，可从同一窗口打开对应的系统设置。macOS 弹出剪贴板读取提示时，允许 OwnClip 读取才能自动记录历史。
3. 如果系统因安装包的下载来源阻止首次打开，按系统提示在「隐私与安全性」确认打开。当前发布版本使用本地自签名，未经 Apple 公证。

## 使用

| 操作 | 默认快捷键 |
| --- | --- |
| 打开剪贴板历史 | `⌘⇧V` |
| 打开顺序粘贴 | `⌘⇧C` |
| 粘贴历史中选中的条目 | `Return` |
| 粘贴为纯文本 | `⌘Return` |
| 粘贴搜索结果或历史的第 1–10 条 | `⌘1` 至 `⌘0` |
| 关闭当前 OwnClip 窗口 | `Esc` 或 `⌘W` |
| 粘贴下一条 | `⌘V` |

在「设置 → 快捷键」中可逐项改键。剪贴板历史快捷键在剪贴板历史面板获得焦点时生效。

「设置 → 通用 → 语言」提供「自动、English、简体中文」，默认自动。自动按系统首选语言匹配英文或简体中文，无法匹配时使用 English。切换后立即生效并保存，无需重启；菜单、面板、权限引导和应用提示同步更新。复制内容、文件名保持原文，macOS 权限弹窗由系统决定语言。

「设置 → 通用 → 登录时自动启动 OwnClip」默认关闭。打开后，macOS 会在你登录账户时启动 OwnClip。

底部长条铺满当前屏幕的宽度，每次打开时从第一张卡片开始。在卡片区域可以用普通鼠标滚轮、`Shift` 加滚轮或触控板横滑来横向滚动。浮动列表可用顶部拖动手柄移动，OwnClip 会记住每块显示器上的位置。打开设置时剪贴板历史面板会保留。`Esc` 和 `⌘W` 关闭当前获得焦点的 OwnClip 窗口；有确认弹框时，先取消确认弹框。录制快捷键时，`Esc` 取消录制，`⌘W` 关闭设置。这两个键保留为标准窗口操作，自定义关闭快捷键仍可额外使用。

剪贴板历史和顺序粘贴使用系统原生弹出窗口材质，随浅色、深色外观变化。横向历史卡片使用浅色模式白色、深色模式对应的系统背景；竖向历史列表未选中时背景透明。历史与顺序粘贴的下一条高亮共用系统选中背景色和配套文字色，均不显示条目边框，缩略图保留原色。三种展示的背景材质及选中配色集中配置在 `Sources/UI/PanelStyle.swift` 的 `PanelStyle` 中，背景保持原生材质效果。macOS 26 及以后，工具栏使用系统 Liquid Glass。开启系统「降低透明度」时，面板改用不透明的系统背景。

若系统开关已打开但 OwnClip 仍显示「未获得授权」，退出并重新打开。从旧的临时签名版本切换到固定证书签名版本时，需要移除旧授权，再添加「应用程序」里的当前版本一次。后续持续使用同一证书和 Bundle ID 构建，通常可以保留授权；若更换签名身份或遇到系统权限异常，仍可能需要重新授权。

主动打开顺序粘贴时，弹框会获得键盘焦点；从历史添加条目时保留历史窗口的焦点。顺序粘贴弹框在所有桌面可见，切换桌面不会清空队列或主动抢焦点。打开后继续在其他应用复制或剪切，按 `⌘V` 逐条粘贴。弹框顶部可切换「用后移除」和「循环使用」。默认的「用后移除」会逐条移除已贴内容，贴完后关闭弹框。「循环使用」保留所有条目，本轮贴过的条目变灰，贴完最后一条后从第一条开始新一轮。反转按钮可调整粘贴顺序。关闭顺序粘贴后，`⌘V` 恢复普通粘贴。顺序粘贴弹框可用顶部拖动手柄或空白区域移动，与剪贴板历史分别记住每块显示器上的位置，关闭重开或重启应用后会恢复。首次打开位于当前屏幕右上角，屏幕尺寸变化时会调整到可见范围内。

文本编辑和 Finder 文件名编辑使用原生 `⌘X`。在设置里开启 Finder 文件移动后，还可以选中文件按 `⌘X`，到目标目录按 `⌘V`，由 Finder 移动文件。

历史存放在 `~/Library/Application Support/OwnClip`，默认保留 1 天，可选 1–7 天。Finder 文件和视频记录保留原文件引用，原文件不可访问时会提示。直接复制的图片和视频数据存到本机。
